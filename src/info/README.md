# Раздел «Участок и дом»

Страница `#/info` строится целиком из `public/data/house.json`. Компонент `InfoPage.tsx` загружает файл при открытии и рисует секции по порядку; пересборка сайта нужна только при правке кода, для правки данных достаточно залить новый JSON.

## Формат house.json

```json
{
  "title": "Участок и дом",
  "subtitle": "…",
  "updated": "2026-09-30",
  "sections": [
    { "id": "docs", "title": "Документы", "lead": "…", "status": "ready|collecting", "blocks": [ … ] }
  ]
}
```

Блоки (`type`), у любого можно указать `title` и `source`:

- `facts` — `items: [{ label, value, hint? }]`, таблица «параметр — значение».
- `text` — `paragraphs: ["…"]`. Внутри строк понимаются `**жирный**`, `[текст](https://…)`, голые ссылки и `` `код` ``.
- `table` — `columns: [..]`, `rows: [[..], ..]`; ячейка-ссылка показывается доменом, дата `YYYY-MM-DD` — как `ДД.ММ.ГГГГ`.
- `links` — `items: [{ title, url, note? }]`.
- `list` — `items: [{ title, status?, note?, date?, url? }]`, используется для документов.
- `note` — `text`, `tone: info|pending|warn`.
- `group` — сворачиваемый блок, `blocks: [...]`.
- `map` — схема участка в метрах: `parcel.points`, необязательные `sides`, `neighbors`, `zone`, `street`, `strip`, `north` — угол на север.

Статусы с цветом: `решено`, `есть`, `готово` — зелёный; `рассматривается`, `в работе` — оранжевый; `нужно` — красный; `позже`, `отменено` — серый.

## Правка данных

`house.json` правится вручную и заливается на хостинг вместе со сборкой; пересборка нужна только при правке кода. Поле `auto` у блока и пометка `status: "collecting"` у секции поддерживаются отображением, но заполнять их не обязательно. В репозитории лежит демо-файл с вымышленным участком — замените его своими данными.

Страница публичная: не кладите сюда ФИО, реквизиты и сканы документов.
