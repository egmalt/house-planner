# Публичное демо

[English](../en/demo.md) | **Русский**

Демо-режим превращает установку в открытую песочницу: планировщик открывается без пароля, правки видят все посетители, а раз в час план возвращается к исходному `plans/demo.json`. Так устроено демо на сайте проекта; для своего дома демо не нужно — ставьте обычную копию.

## Что меняется

Вход не нужен: API не спрашивает куку, экран пароля не показывается, `data/` и `plans/` открыты. Сверху страницы — тонкая плашка «Демо: изменения видят все и сбрасываются каждый час» со ссылкой на GitHub. Раз в час план сбрасывается к `plans/demo.json`, версии и снимки старше часа удаляются. Ограничения против злоупотреблений: план не больше 1 МБ, не больше 30 сохранений в минуту с одного IP (дальше `429`), не больше 20 снимков, корзина Петровича отключена (кнопка неактивна, API отвечает `403 demo_disabled`). Подробности и коды ответов — в [docs/api.md](../../api.md#демо-режим).

## Docker

```bash
HOUSE_DEMO=1 docker compose up -d --build
```

Пароль задавать не нужно: загрузчик сам установит планировщик со случайным паролем и откроет `data/` и `plans/`. План сбрасывается лениво — первым запросом после того, как с прошлого сброса прошёл час.

## Виртуальный хостинг

Установите планировщик как обычно ([deploy.md](deploy.md)), затем допишите в `storage/config.php` ключ:

```php
'demo' => true,
```

и добавьте cron от пользователя веб-сервера:

```cron
0 * * * * php /home/user/house-planner/scripts/demo-reset.php --webroot=/home/user/www/plan.example.com
```

`--webroot` — корень сайта, куда залит `dist/`; скрипт берёт оттуда `api/_lib.php` и `plans/demo.json`, хранилище ищет так же, как API (`HOUSE_STORAGE`, `../storage`, `storage`). Первый запуск сразу открывает `data/` и `plans/`. Без cron работает ленивый сброс, как в Docker.

## Как выключить

Уберите ключ `demo` (или переменную `HOUSE_DEMO`), затем закройте статику заново: в Docker — `docker compose exec house-planner rm /var/lib/house-planner/config.php` и `HOUSE_PASSWORD=<пароль> docker compose up -d` (пароль демо-установки случайный и никому не известен), на хостинге — удалить `config.php` в хранилище и пройти `api/setup.php` с новым паролем (план и версии останутся). Токен куки после демо лучше сменить именно так: пока шло демо, `data/` и `plans/` были открыты.
