# Частые вопросы

[English](../en/faq.md) | **Русский**

### Нужен ли сервер и база данных?

Нужен веб-сервер с PHP 8.1+, базы данных не нужно. План, его версии и конфигурация — обычные файлы в папке `storage/`. Хватит дешёвого виртуального хостинга с Apache или LiteSpeed, Docker-образа или `php -S` на своём компьютере. Node.js нужен только для сборки. См. [install.md](install.md).

### Как сменить пароль?

Удалите `config.php` в хранилище и снова откройте `/api/setup.php`. План и история остаются, все входы сбрасываются: создаётся новый токен куки. В Docker: `docker compose exec house-planner rm /var/lib/house-planner/config.php`, затем перезапуск с новым `HOUSE_PASSWORD` или мастер. Подробно — [install.md](install.md#docker), [deploy.md](deploy.md#смена-пароля).

### Можно ли нескольким людям? Есть ли учётные записи?

Пароль один на установку, учётных записей и ролей нет: кто знает пароль, тот и правит. Одновременная работа при этом безопасна: каждое сохранение несёт ревизию, от которой правили, поэтому две вкладки, два человека или скрипт молча друг друга не перезапишут. У каждой ревизии есть метка автора (`web`, `cli` или то, что задано в `plan-push.sh --author`). Для разных проектов поднимайте разные установки: другая папка на хостинге или другой Docker-контейнер со своим портом и томом.

### Где хранятся данные и как делать резервные копии?

В папке хранилища: `config.php`, `current.json` (текущий план), `versions/` (все сохранённые ревизии, хранятся всегда), `snapshots/` (именованные снимки). На хостинге это обычно `../storage` рядом с корнем сайта, в Docker — том `house-data`. Копируйте папку целиком. Копия одного плана — «⋯» → «Экспорт JSON» или `scripts/plan-pull.sh`. Команды — в [deploy.md](deploy.md#резервные-копии).

### Как обновиться?

`git pull`, `npm ci`, `scripts/deploy.sh` (или залить новый `dist/` вручную, не трогая `storage/`, `data/.htaccess`, `plans/.htaccess`). В Docker: `git pull && docker compose up -d --build`. Хранилище не затрагивается. Перед обновлением загляните в [CHANGELOG.md](../../../CHANGELOG.md).

### Как загрузить свой участок?

1. Получите полигон участка в GeoJSON в долготе и широте (WGS84): выгрузите из публичной кадастровой карты (НСПД) или нарисуйте в любой ГИС (QGIS, geojson.io).
2. Откройте «Карта», разверните «Граница из GeoJSON», вставьте `Polygon`, `Feature` или `FeatureCollection`, оставьте «Вычислить geo по полигону» и выберите вершину, которая станет началом координат плана.
3. «Пересчитать», проверьте площадь и размеры, затем «Применить к плану». Граница станет `site.boundary` в миллиметрах, а `site.geo` привяжет план к карте.
4. Если спутниковый снимок сдвинут относительно границы, выровняйте снимок сдвигом и поворотом; хранится только поправка снимка.

Смежные участки показываются из `public/data/parcel.geojson` (`FeatureCollection`). Чтобы юридическую границу нельзя было сдвинуть ни из редактора, ни скриптом, положите в хранилище `site-fixed.json` — пример в `storage.example/site-fixed.example.json`, описание в [docs/api.md](../../api.md).

### Как добавить материал в каталог?

Каталог — `public/data/catalog.json`, массив позиций:

```json
{ "id": "block-d500-600x300x200", "name": "Газобетонный блок D500 600×300×200", "kind": "block",
  "vendor": "Название магазина", "url": "https://…", "sku": "123456",
  "thickness": 300, "length": 600, "height": 200,
  "price": 290, "unit": "шт", "checkedAt": "2026-10-01" }
```

`kind` определяет, где позиция используется (`sip`, `pir`, `block`, `timber`, `door`, `window`, `gate`, `insulation`, `sewer`, `water`, `heating`, `electric` и другие); `unit` — `шт`, `м²`, `м` и т. д.; `preferred: true` выигрывает у более дешёвых совпадений; `sku` — код товара Петровича. Правила подбора для каждой сети — в [docs/plan-format.md](../../plan-format.md). Каталог грузится при работе, поэтому после правки достаточно залить `data/catalog.json`, пересборка не нужна. Материал, нужный только в одном плане, можно вместо этого добавить в `materials` самого плана с `price`.

### Цены настоящие?

Это пример, собранный по магазинам Санкт-Петербурга на дату из поля `checkedAt` каждой позиции. Это не оферта, цены устаревают и могут не подходить для вашего региона. Считайте каталог шаблоном и ведите свой.

### Насколько можно доверять проверкам по нормам?

Это справочные проверки по СП 30.13330, ПУЭ, ГОСТ Р 50571, СанПиН и упрощённые инженерные формулы. Они рано ловят типичные ошибки, но не заменяют проект, сделанный специалистом, и местные требования.

### Работает ли на телефоне?

Да, на просмотр. На экране уже 700 px или на устройстве только с сенсором приложение переходит в режим просмотра: план, 3D, карта, смета и страница участка работают, на сервер ничего не пишется. Для правки нужна мышь или тачпад.

### Как работает корзина Петровича?

«Смета» → «Собрать корзину в Петровиче». Серверный `api/petrovich-cart.php` открывает анонимную сессию на petrovich.ru, находит товары по кодам, кладёт их в корзину, получает публичную ссылку на смету и очищает корзину. Ссылка выдаётся на каждый раздел (дом, гараж, электрика, канализация, водопровод, тёплый пол, прочее); открыть её может кто угодно и одной кнопкой перенести позиции в свою корзину.

Ограничения:

- Попадают только позиции с кодом товара Петровича (`sku` или ссылка вида `petrovich.ru/product/<код>/`). Другие магазины пропускаются.
- Два города: Санкт-Петербург и Выборг. Чего нет в наличии в выбранном городе, пропускается и показывается списком.
- До 150 разных позиций за запрос, один запрос за раз (второй получает `429`), предел 120 с.
- Цены в ответе — розничные цены Петровича без скидок корзины.
- Используется API сайта Петровича, а не официальная интеграция: может сломаться при их изменениях, а защита от ботов может заблокировать IP хостинга (`502 petrovich_blocked`).
- Каждый вызов создаёт у них новую смету, удалить её анонимно нельзя, поэтому не дёргайте в цикле.
- Нужно расширение PHP `curl`.

### Можно ли без интернета?

В основном да. Запущенный локально (Docker или `php -S`) редактор, 3D, сети и смета работают в локальной сети без выхода в интернет. Интернет нужен для спутниковой подложки (тайлы Esri World Imagery), корзины Петровича и ссылок на товары. Шрифты и скрипты со сторонних CDN приложение не грузит.

### На каких языках интерфейс?

На английском и русском. По умолчанию английский независимо от языка браузера; переключается в меню «⋯» → «Язык» (выбор запоминается) или параметром `?lang=ru` / `?lang=en` в ссылке. Переводы на другие языки приветствуются: строки лежат в `src/i18n/locales/<язык>/`, см. [CONTRIBUTING.md](../../../CONTRIBUTING.md).
